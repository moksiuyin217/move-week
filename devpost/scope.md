# NTC Screenshot Workout Planner

Turn workout names and durations in an NTC screenshot into a scheduled text plan or calendar file, with a short guide for importing the calendar file into Google Calendar or Apple Calendar.

## The Unique Kernel
Move workout names from a screenshot into a usable daily plan without retyping each name. The learner reviews extracted workout names and durations, chooses what to schedule, assigns dates and start times, and gets text or calendar events ready to use. The duration sets each calendar event’s end time.

## Who It's For
People who plan workouts from a screenshot and want to add them to a daily plan without retyping. Other people who use a calendar as their to-do list could also use the calendar-file output.

## The Core Loop
Upload a screenshot of the workout list; review extracted names and durations and select the workouts to include; assign a date and start time to each; copy the formatted text into Notion or download a calendar file with the end time calculated from the workout duration, then follow the import guide.

## Inspiration & Identity
Organized databases can help people manage hobbies and health. No visual style preference established.

## Why This Matters to the Learner
Workout planners want their selected sessions in a daily plan without manually retyping names or durations. Calendar entries may also help people who use a calendar as their to-do list.

## What "Working" Looks Like
Given a screenshot like the one shared, the app extracts workout names and durations. The learner can review the results, choose which workouts to use, assign a date and start time to each, and get scheduled text ready to paste or a calendar file with timed events. The end time is calculated from the workout’s duration. A short guide explains how to import the file into Google Calendar or Apple Calendar. The demo moment is seeing the screenshot’s workouts become scheduled plans without retyping their names or durations.

## The POC Boundary
A small website that accepts a workout screenshot, extracts workout names and durations, lets the learner review and select them, collects a date and start time for each selected workout, and produces paste-ready text containing the date, start time, and workout name plus a downloadable calendar file with timed events. Calculate each event’s end time using its extracted duration. Include a short guide with the steps for importing that file into Google Calendar and Apple Calendar.

## Later

- Bringing Nike Run Club runs and run details into the plan.

## Explicitly Cut

- NRC run logging and weekly distance tracking: the learner chose planned NTC workouts as the first slice.
- Workout difficulty in the generated plan: it is not needed to prove the screenshot-to-scheduled-plan idea.
